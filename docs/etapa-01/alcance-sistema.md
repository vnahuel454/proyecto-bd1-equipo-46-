El sistema deberá proporcionar:

Control de Stock: Controlará el reabastecimiento de mercaderías a través del vínculo con los proveedores externos, registrando las existencias actuales. Ante un nivel de stock mínimo permitido, deberá emitir una alerta automática de reposición.
   
Facturación: Se registrará cada venta de forma precisa asociada al legajo del cajero interviniente. Detallará la fecha, hora, artículos adquiridos, cantidad vendida, IVA, descuentos, el importe total y el precio unitario cobrado al momento exacto de la operación (precio histórico). Asimismo, registrará el monto imputado a cada medio de pago seleccionado, permitiendo combinar formas de pago simultáneas.
   
Clientes: Registro de datos para el programa de beneficios de clientes frecuentes, permitiendo en paralelo la asociación a un registro genérico por defecto para consumidores finales no registrados.
